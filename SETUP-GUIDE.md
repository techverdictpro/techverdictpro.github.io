## 🔧 Инсталация и Настройка

### Стъпка 1: Хостинг Setup

```bash
# 1. Купи хостинг и домейн (напр. SiteGround)

# 2. Инсталирай Node.js на сървъра (чрез SSH)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 3. Проверка
node --version  # Трябва да е v20+
npm --version
```

### Стъпка 2: Качи Файловете

```bash
# Качи всички файлове на сървъра чрез FTP/SFTP
# Или използвай Git:

# На сървъра:
cd /home/youruser/
git clone your-repo-url techwise-pro
cd techwise-pro
```

### Стъпка 3: Инсталирай Dependencies

```bash
# В директорията на проекта:
npm init -y

# Инсталирай Claude SDK
npm install @anthropic-ai/sdk

# Допълнителни packages
npm install dotenv  # За environment variables
npm install node-cron  # За scheduling
```

### Стъпка 4: Environment Variables

Създай `.env` файл:

```env
# .env file
ANTHROPIC_API_KEY=sk-ant-your-actual-key-here

# Affiliate IDs
AMAZON_TAG=yoursite-20
EBAY_CAMPAIGN_ID=your-campaign-id
ALIEXPRESS_AFFILIATE_ID=your-affiliate-id

# Site Settings
SITE_URL=https://yoursite.com
SITE_NAME=TechWise Pro

# AdSense
ADSENSE_ID=ca-pub-your-id-here
```

### Стъпка 5: Настрой Конфигурацията

Редактирай `auto-content-generator.js`:

```javascript
const CONFIG = {
    anthropicApiKey: process.env.ANTHROPIC_API_KEY,
    
    // Персонализирай нишите за България/твоя пазар:
    niches: [
        'gaming laptops',
        'wireless headphones',
        'smart watches',
        // Добави твои niches тук
    ],
    
    affiliateLinks: {
        amazon: `https://www.amazon.com/?tag=${process.env.AMAZON_TAG}`,
        ebay: `https://www.ebay.com/partner/${process.env.EBAY_CAMPAIGN_ID}`,
        aliexpress: `https://www.aliexpress.com/?aff=${process.env.ALIEXPRESS_AFFILIATE_ID}`
    },
    
    articlesPerDay: 4,  // Започни с 3-4
    outputDir: './generated-content'
};
```

### Стъпка 6: First Run (Тест)

```bash
# Генерирай първо съдържание (тест):
node auto-content-generator.js --once

# Провери output:
ls -la generated-content/

# Виж една генерирана статия:
cat generated-content/*.html | head -50
```

### Стъпка 7: Автоматизация с Cron

```bash
# Редактирай crontab:
crontab -e

# Добави ред за автоматично генериране всеки ден в 2:00 AM:
0 2 * * * cd /home/youruser/techwise-pro && /usr/bin/node auto-content-generator.js --once >> logs/cron.log 2>&1

# Запази и затвори
```

### Стъпка 8: Web Server Setup (Nginx)

```nginx
# /etc/nginx/sites-available/techwise-pro

server {
    listen 80;
    server_name yoursite.com www.yoursite.com;
    
    root /home/youruser/techwise-pro;
    index auto-revenue-site.html;
    
    location / {
        try_files $uri $uri/ =404;
    }
    
    # Generated content
    location /articles/ {
        alias /home/youruser/techwise-pro/generated-content/;
    }
    
    # CSS
    location /styles/ {
        alias /home/youruser/techwise-pro/styles/;
    }
}
```

```bash
# Активирай конфигурацията:
sudo ln -s /etc/nginx/sites-available/techwise-pro /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Стъпка 9: SSL Certificate (HTTPS)

```bash
# Инсталирай Certbot:
sudo apt install certbot python3-certbot-nginx

# Получи безплатен SSL:
sudo certbot --nginx -d yoursite.com -d www.yoursite.com

# Auto-renewal:
sudo certbot renew --dry-run
```

## 📊 SEO Оптимизация

### On-Page SEO Checklist

```
✅ Title Tags:
- Max 60 characters
- Include main keyword
- Format: "Best [Product] 2026 - Complete Review & Comparison"

✅ Meta Descriptions:
- 150-160 characters
- Include CTA
- Natural keyword usage

✅ Headers:
- H1: One per page (main keyword)
- H2-H3: Structure content
- Include variations of keywords

✅ Internal Linking:
- Link to related articles
- 3-5 internal links per article
- Use descriptive anchor text

✅ Image Optimization:
- Alt text with keywords
- Compress images (WebP format)
- Descriptive file names

✅ URL Structure:
- Short and descriptive
- Include keyword
- Example: /best-gaming-laptop-2026/
```

### Technical SEO

```
✅ Site Speed:
- Use CloudFlare CDN (free)
- Enable Gzip compression
- Minify CSS/JS
- Target: <3 seconds load time

✅ Mobile Optimization:
- Responsive design
- Touch-friendly buttons
- Fast mobile loading

✅ Schema Markup:
- Product schema
- Review schema
- Article schema
(AI generator добавя автоматично)

✅ XML Sitemap:
- Submit to Google Search Console
- Update weekly

✅ Robots.txt:
- Allow all search engines
- Block admin pages
```

### Content SEO Strategy

**Keyword Research:**
```bash
# Използвай Ubersuggest или Google Keyword Planner:

Target keywords:
- "best [product] 2026" - High intent
- "[product] review" - High intent
- "[product] vs [competitor]" - Comparison
- "top [product] under [price]" - Budget

Sweet spot:
- Search volume: 1,000-10,000/month
- Keyword difficulty: <30
- Commercial intent: High
```
